# flowmore

Take any AI platform further. Capability maps + prompt practice with a live quality bar.

## Develop

```bash
npm install
npm run dev
```

Optional: set `OPENAI_API_KEY` (or `AI_GATEWAY_API_KEY`) for AI-backed chat and rating. Without a key, local practice replies and scoring still work.

## Deploy

Deploy to Vercel. Add the optional API key in project environment variables if you want model-backed responses.
